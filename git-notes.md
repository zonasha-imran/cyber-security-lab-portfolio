# Basic Git Commands

1. git status
Shows the current state of the repository.

2. git add
Adds changes to the staging area.

3. git commit
Saves staged changes in the repository.

4. git push
Uploads local commits to GitHub.

5. git pull
Downloads and integrates changes from GitHub.

6. git remote -v
Displays the URLs of remote repositories connected to the local repository.

7. git init
Initializes a new Git repository in the current directory.

8. git log --oneline
Displays the commit history in a short, one-line format.
